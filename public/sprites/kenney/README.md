# Kenney Tiny Dungeon sprites

These sprites are selected unchanged from **Kenney Tiny Dungeon 1.0** (16×16 pixel art).

Source: https://kenney.nl/assets/tiny-dungeon
License: Creative Commons Zero (CC0 1.0). See `LICENSE.txt`.

Threadbound mappings:
- `weaver-*.png`: deterministic player character variants
- `frayed-wisp.png`: tile 0121
- `hollow-stalker.png`: tile 0120
- `silkbound-guard.png`: tile 0096
- `boss.png`: tile 0110

The original art is vendored so gameplay never depends on an external image host or API.
